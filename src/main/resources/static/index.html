Before you upload, please note:
  • Both Tally and GST files must follow the same column layout as the sample template.
  • Columns expected: Month, GSTIN, Party Name, Invoice Number, Invoice Date, Taxable Value, IGST, SGST, CGST
  • The Aggregate Field is used to compare total sums per GSTIN. If totals match, that GSTIN is excluded from all sheets.
  • Tolerance allows a small acceptable difference (e.g. rounding). Set to 0 for exact match.
  • The report is available for download immediately after processing. Download it right away — files are not stored permanently.
